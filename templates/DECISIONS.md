# Decisions — append only

One entry per real decision. Never edit or delete an entry; if a decision is
reversed, add a new entry that says so and why. The most valuable line in each entry
is the **rejected alternative** — that is what stops a future session from
re-litigating a question that is already settled, or from happily walking into the
option that was already ruled out.

Do not put the plan here (that is `STATE.md`) and do not put debugging notes here
(that is `GOTCHAS.md`). This file is decisions and their evidence, nothing else.

---

## <date> — <decision in one line>

- **Context:** what question was open, and what triggered it.
- **Decision:** what was chosen.
- **Rejected:** the alternative, and the specific reason it lost.
- **Evidence:** the source — a URL, an exact string from a tool or config, a query
  result. Not "it seemed better".
- **Council:** which voices ran, and whether they disagreed.
- **Would change this:** the one thing that would make us revisit it.
